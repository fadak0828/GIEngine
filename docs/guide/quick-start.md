# 빠른 시작 — AI Quick Create로 5분 안에 첫 게임 만들기

> **사전 준비**: Gemini API 키가 필요합니다. [Google AI Studio](https://aistudio.google.com/)에서 무료로 발급받을 수 있습니다.

---

## 1단계 — API 키 설정

1. 에디터 상단 툴바에서 **⚙ AI 설정** 버튼을 클릭합니다.
2. Gemini API 키를 입력하고 **저장**합니다.
   - 키는 브라우저 localStorage에만 저장되며 서버로 전송되지 않습니다.

---

## 2단계 — Quick Create 실행

1. 툴바에서 **✨ Quick Create** 버튼을 클릭합니다.
2. 텍스트 입력란에 사건을 한 문장으로 묘사합니다.

   **예시 문장:**
   ```
   점심시간 카페에서 파티시에 바리스타가 독을 넣었다
   고성 무도회 밤에 백작의 조카가 심장을 찔렸다
   지방 연구소에서 수석 과학자가 실험체 약물로 살해됐다
   ```

3. (선택) **장르**, **분위기**, **시대** 옵션을 설정합니다.
4. **생성 시작** 버튼을 클릭합니다.

---

## 3단계 — 변형 선택 (옵션)

AI가 분석 결과를 제시하면 4개 섹션별로 원하는 방향을 선택할 수 있습니다:

| 섹션 | 내용 |
|------|------|
| **캐릭터 구성** | 주요 인물과 용의자 배치 |
| **씬 배치** | 탐색 장면 구성 방식 |
| **퍼즐 구조** | 핵심 질문과 단서 연결 방식 |
| **분위기/스타일** | 전체적인 비주얼 분위기 |

선택을 건너뛰면 AI가 자동으로 결정합니다.

---

## 4단계 — 블루프린트 확인 및 적용

1. 생성이 완료되면 **블루프린트 미리보기** 창이 열립니다.
2. 생성된 씬, 단어, 퍼즐 구조를 확인합니다.
3. **프로젝트에 적용** 버튼을 클릭하면 에디터에 바로 로드됩니다.

---

## 5단계 — 게임 저장 및 익스포트

1. **Ctrl + S** (또는 툴바의 💾 **저장**)로 `.gi-project` 파일을 저장합니다.
2. 툴바의 **📤 익스포트**를 클릭해 독립 실행 HTML 파일을 다운로드합니다.
3. 다운로드한 `.html` 파일을 브라우저에서 열면 게임을 바로 플레이할 수 있습니다.
