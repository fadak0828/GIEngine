# 오디오 시스템 — BGM과 효과음

GIEngine은 두 가지 오디오 채널을 지원합니다: **BGM**(배경음악)과 **SFX**(효과음).

---

## 오디오 에셋 업로드

1. **에셋 관리** 탭으로 이동합니다 (`Ctrl+2`).
2. **+ 에셋 추가** 버튼을 클릭합니다.
3. 오디오 파일(`.mp3`, `.wav`, `.ogg`)을 선택합니다.
4. 에셋이 업로드되면 **카테고리**를 설정합니다:
   - `audio_bgm` — 배경음악용
   - `audio_sfx` — 효과음용

---

## 오디오 편집 모달

에셋 목록에서 오디오 에셋을 선택하면 **오디오 편집 모달**이 열립니다.

### 주요 기능

| 기능 | 설명 |
|------|------|
| **재생/정지** | 업로드된 오디오를 미리 들어봅니다 |
| **트림** | 시작·끝 지점을 지정해 원하는 구간만 잘라냅니다 |
| **타임라인** | 파형을 시각적으로 확인하고 마커를 드래그합니다 |
| **볼륨 조정** | 트림된 구간의 볼륨을 조정합니다 |
| **저장** | 편집 결과를 WAV(16-bit PCM)로 저장합니다 |

---

## BGM 설정

### 씬 BGM

씬 진입 시 자동으로 배경음악을 재생합니다.

1. 씬을 선택합니다.
2. 속성 패널에서 **BGM** 항목을 클릭합니다.
3. 에셋 목록에서 `audio_bgm` 카테고리의 에셋을 선택합니다.

BGM은 씬을 이동해도 계속 재생됩니다. 다른 씬에서 새 BGM을 설정하면 교체됩니다.

### BGM 정지

씬 속성의 **BGM 정지(bgmStop)** 옵션을 활성화하면 해당 씬 진입 시 현재 BGM이 멈춥니다. 긴장감 있는 장면 전환에 활용합니다.

---

## 효과음 설정

핫스팟 액션에서 `play_sound`를 선택합니다.

1. 핫스팟을 선택합니다.
2. 속성 패널에서 **액션 타입 → play_sound**를 설정합니다.
3. `audio_sfx` 카테고리의 에셋을 선택합니다.

### composite 액션으로 효과음 + 텍스트 조합

```
composite 액션:
  1. play_sound  → 발견 효과음
  2. examine     → "단서를 발견했다!" 텍스트 팝업
```

이 조합으로 클릭 시 효과음을 재생하면서 텍스트를 표시합니다.

---

## BGM 페이드

`play_bgm` Side Effect에는 선택적으로 `fadeDuration`(밀리초)을 지정해 BGM을 부드럽게 교체할 수 있습니다. 이 설정은 onEnter 시퀀스 또는 컴포지트 액션에서 사용됩니다.

---

## 지원 형식

| 형식 | 권장 용도 |
|------|----------|
| `.mp3` | BGM (파일 크기가 작아 배포에 유리) |
| `.wav` | 효과음 (낮은 지연 시간) |
| `.ogg` | BGM/SFX 공용 (Chromium 기반 브라우저) |

> **익스포트 시**: 오디오는 Base64로 인코딩되어 HTML 내에 포함됩니다. 파일이 클수록 익스포트 크기가 늘어납니다.
