# 씬 관리 — 생성, 핫스팟, 레이어

씬(Scene)은 플레이어가 탐색하는 하나의 장면입니다. 배경 이미지, 핫스팟(클릭 영역), 레이어(전환 가능한 이미지)로 구성됩니다.

---

## 씬 생성

1. 왼쪽 **프로젝트 트리**에서 케이스를 선택합니다.
2. 케이스 항목 옆 **+** 버튼을 클릭합니다.
3. 씬 이름을 입력하고 확인합니다.
4. 씬을 선택하면 중앙 캔버스에 빈 씬이 표시됩니다.

---

## 씬 속성 설정

씬을 선택한 상태에서 오른쪽 **속성 패널**에서 편집합니다.

| 속성 | 설명 |
|------|------|
| **배경 이미지** | 에셋 관리에서 업로드한 이미지를 선택합니다 |
| **치수** | 씬의 가로/세로 크기 (기본값: 1280×720) |
| **BGM** | 씬 진입 시 자동 재생할 배경음악 |
| **BGM 정지** | 씬 진입 시 현재 BGM을 정지할지 여부 |
| **스크롤 허용** | 씬이 뷰포트보다 클 때 드래그 패닝 허용 |

---

## 핫스팟 추가

핫스팟은 플레이어가 클릭할 수 있는 상호작용 영역입니다.

### 핫스팟 추가 방법

1. **씬 편집** 탭에서 캔버스를 확인합니다.
2. 캔버스 위에서 **마우스를 드래그**해 직사각형 핫스팟을 그립니다.
3. 그려진 핫스팟을 클릭하면 속성 패널에서 상세 설정을 합니다.

### 핫스팟 영역 타입

| 타입 | 설명 |
|------|------|
| `rect` | 직사각형 (x, y, width, height) |
| `circle` | 원 (cx, cy, radius) |
| `polygon` | 다각형 (점 배열) |

### 핫스팟 액션 타입

| 액션 | 설명 |
|------|------|
| **examine** | 텍스트 팝업 표시. 단어 수집 포함 가능 |
| **examine_image** | 이미지 팝업 표시 (내부 핫스팟 중첩 가능) |
| **word_reveal** | 단어를 즉시 수집 |
| **navigate** | 다른 씬으로 이동 (fade, slide 전환 효과) |
| **toggle_layer** | 레이어 표시/숨김 전환 |
| **play_sound** | 효과음 재생 |
| **composite** | 여러 액션을 순서대로 실행 |

### 표시 조건 (Condition)

핫스팟이 표시되는 조건을 설정합니다:

| 조건 타입 | 설명 |
|----------|------|
| `layer_visible` | 특정 레이어가 표시 중일 때 |
| `word_collected` | 특정 단어를 수집했을 때 |
| `puzzle_solved` | 특정 퍼즐을 해결했을 때 |
| `and` / `or` / `not` | 복합 조건 |

---

## 레이어 관리

레이어는 배경 위에 겹쳐 표시되는 이미지입니다. `toggle_layer` 액션으로 게임 중 표시/숨김을 전환할 수 있습니다.

### 레이어 추가 방법

1. 씬 속성 패널에서 **레이어 추가** 버튼을 클릭합니다.
2. 에셋에서 이미지를 선택합니다.
3. 위치(x, y)와 z-인덱스(레이어 순서)를 설정합니다.

### 레이어 속성

| 속성 | 설명 |
|------|------|
| **이미지** | 표시할 에셋 이미지 |
| **위치** | 배경 기준 좌상단 좌표 (x, y) |
| **z-인덱스** | 레이어 겹침 순서 (숫자가 클수록 앞에 표시) |
| **초기 가시성** | 씬 시작 시 표시 여부 |

---

## 씬 전환

핫스팟의 `navigate` 액션으로 씬 간 이동을 설정합니다.

| 전환 효과 | 설명 |
|----------|------|
| `fade` | 페이드 아웃 → 페이드 인 |
| `slide_left` | 왼쪽으로 슬라이드 |
| `slide_right` | 오른쪽으로 슬라이드 |
| `instant` | 즉시 전환 (효과 없음) |

---

## onEnter 시퀀스

씬 진입 시 자동으로 실행할 액션 시퀀스를 설정할 수 있습니다.

예시: 씬에 진입하자마자 특정 레이어를 숨기고, 0.5초 대기 후 효과음을 재생하는 시퀀스.
