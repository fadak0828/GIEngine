# 게임 익스포트 — 독립 실행 HTML 만들기

GIEngine은 완성된 게임을 **단일 HTML 파일**로 내보냅니다. 외부 서버나 별도 설치 없이 브라우저에서 바로 실행됩니다.

---

## 익스포트 실행

1. 툴바에서 **📤 익스포트** 버튼을 클릭합니다.
2. **익스포트 모달**이 열립니다.

---

## 익스포트 모드 선택

| 모드 | 설명 |
|------|------|
| **Production** | 코드가 최소화(minify)됩니다. 배포용 권장 |
| **Development** | 소스맵 포함, 디버깅 용이. 개발 중 테스트용 |

---

## 검증 확인

익스포트 전에 자동으로 프로젝트를 검증합니다. 오류가 있으면 경고가 표시됩니다.

- **오류(Error)**: 익스포트를 차단합니다. 반드시 수정해야 합니다.
- **경고(Warning)**: 익스포트는 가능하지만 게임 품질에 영향을 줄 수 있습니다.

검증 상세 결과는 에디터의 **검증** 탭에서도 확인할 수 있습니다.

---

## 파일 크기 분석

익스포트가 완료되면 파일 크기 분석 결과를 보여줍니다.

| 항목 | 설명 |
|------|------|
| **JS** | 런타임 엔진 코드 |
| **CSS** | 스타일시트 |
| **에셋** | 이미지·오디오 (Base64 인코딩) |
| **데이터** | 게임 정의 JSON |

> 에셋이 전체 파일 크기의 대부분을 차지합니다. 이미지를 압축하고 오디오를 MP3로 사용하면 크기를 줄일 수 있습니다.

---

## 다운로드

**다운로드** 버튼을 클릭하면 `{게임ID}.html` 파일이 저장됩니다.

---

## 게임 실행

다운로드한 HTML 파일을 브라우저에서 열면 게임이 시작됩니다.

```
game.html  →  브라우저에서 열기  →  바로 플레이
```

- 인터넷 연결 없이 오프라인에서도 동작합니다.
- 파일 하나만 있으면 어디서든 실행됩니다.
- 파일을 그대로 웹 서버에 올리면 URL로 공유할 수 있습니다.

---

## 프로그래밍 방식 익스포트

에디터를 거치지 않고 코드에서 직접 익스포트할 수도 있습니다.

```ts
import { bundle } from '@gi-engine/exporter';

const result = await bundle({
  project: gameDefinition,
  outputPath: './game.html',
});
```

빌드 파이프라인이나 CI/CD에서 활용할 수 있습니다.

---

## 저장 파일 형식

에디터에서 저장한 `.gi-project` 파일은 JSON 형식입니다.

```json
{
  "definition": { /* GameDefinition */ },
  "words": [ /* Word[] */ ]
}
```

이 파일은 에디터에서 다시 불러올 수 있으며, 버전 관리(git 등)에도 적합합니다.
