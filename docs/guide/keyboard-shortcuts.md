# 키보드 단축키 참조표

> Mac에서는 `Ctrl` 대신 `⌘ (Cmd)` 를 사용하세요.

---

## 파일 작업

| 단축키 | 동작 |
|--------|------|
| `Ctrl + N` | 새 프로젝트 |
| `Ctrl + S` | 프로젝트 저장 |

---

## 편집

| 단축키 | 동작 |
|--------|------|
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + Y` | 다시 실행 |
| `Ctrl + Shift + Z` | 다시 실행 (대체 단축키) |

---

## 패널 전환

| 단축키 | 동작 |
|--------|------|
| `Ctrl + 1` | 씬 편집 탭 |
| `Ctrl + 2` | 에셋 관리 탭 |
| `Ctrl + 3` | 단어 관리 탭 |
| `Ctrl + 4` | 퍼즐 편집 탭 |

---

## 인터페이스

| 단축키 | 동작 |
|--------|------|
| `?` 또는 `Ctrl + /` | 단축키 도움말 열기/닫기 |
| `Esc` | 모달 / 오버레이 닫기 |

---

## 인라인 참조

에디터 내에서 언제든 `?` 키를 누르면 이 참조표와 동일한 단축키 도움말 모달이 열립니다.
