# 에디터 기본 조작 — 패널 구성과 네비게이션

---

## 전체 레이아웃

에디터는 세 개의 패널과 상단 툴바로 구성됩니다.

```
┌─────────────────────────────────────────────────────┐
│                     툴바 (Toolbar)                   │
├──────────┬──────────────────────────┬───────────────┤
│          │  탭 바 (Tab Bar)          │               │
│  프로젝트 ├──────────────────────────┤  속성 패널     │
│  트리     │                          │  (Properties) │
│  (Left)  │     중앙 캔버스 / 편집 뷰  │               │
│          │                          │               │
│          ├──────────────────────────┤               │
│          │  미리보기 패널 (Preview)   │               │
└──────────┴──────────────────────────┴───────────────┘
```

---

## 상단 툴바

| 버튼 | 단축키 | 설명 |
|------|--------|------|
| ＋ 새 프로젝트 | `Ctrl+N` | 빈 프로젝트를 새로 만듭니다 |
| 📂 열기 | — | `.gi-project` 또는 `.json` 파일을 불러옵니다 |
| 💾 저장 | `Ctrl+S` | 현재 프로젝트를 파일로 저장합니다 (미저장 시 `*` 표시) |
| ↩ 실행 취소 | `Ctrl+Z` | 마지막 작업을 취소합니다 |
| ↪ 다시 실행 | `Ctrl+Y` | 취소한 작업을 다시 실행합니다 |
| 📤 익스포트 | — | 독립 실행 HTML 파일로 게임을 내보냅니다 |
| ✨ Quick Create | — | AI로 게임 구조를 자동 생성합니다 |
| ⚙ AI 설정 | — | Gemini API 키를 설정합니다 |
| KO / EN | — | 에디터 표시 언어를 전환합니다 |

---

## 왼쪽 패널 — 프로젝트 트리

프로젝트의 계층 구조를 표시합니다.

```
프로젝트
└── 막 (Act)
    └── 케이스 (Case)
        └── 씬 (Scene)
```

- 항목을 클릭하면 해당 항목이 **선택**됩니다.
- 케이스를 선택해야 단어 관리와 퍼즐 편집이 활성화됩니다.
- 씬을 선택하면 중앙 캔버스에 해당 씬이 표시됩니다.
- **+** 버튼으로 막, 케이스, 씬을 추가할 수 있습니다.

---

## 중앙 영역 — 탭 패널

탭 바에서 작업 유형을 선택합니다.

| 탭 | 단축키 | 내용 |
|----|--------|------|
| **씬 편집** | `Ctrl+1` | 선택한 씬의 캔버스를 표시합니다. 핫스팟 배치, 레이어 관리 |
| **에셋 관리** | `Ctrl+2` | 이미지·오디오 에셋 업로드 및 관리 |
| **단어 관리** | `Ctrl+3` | 선택한 케이스의 단어 목록 편집 |
| **퍼즐 편집** | `Ctrl+4` | 메인 퍼즐의 슬롯과 정답 설정 |
| **서브 퍼즐** | — | 추가 서브 퍼즐 편집 |
| **검증** | — | 프로젝트 오류 및 경고 확인 |

---

## 오른쪽 패널 — 속성 패널

선택한 요소(씬, 핫스팟, 에셋 등)의 세부 속성을 편집합니다.

- **씬 선택 시**: 배경 이미지, 치수, BGM, 스크롤 설정
- **핫스팟 선택 시**: 영역 타입, 액션 타입, 표시 조건
- **에셋 선택 시**: 파일 정보, 태그, 폴더

---

## 하단 — 미리보기 패널

씬 편집 탭에서 하단에 **게임 미리보기**가 표시됩니다.

- 실제 런타임과 동일한 방식으로 씬을 렌더링합니다.
- 핫스팟 클릭·텍스트 팝업·레이어 전환을 실시간으로 확인할 수 있습니다.
- **▶ 미리보기** 버튼으로 패널을 열고 닫을 수 있습니다.

---

## 기본 워크플로

1. **새 프로젝트** → 막/케이스/씬 구조 생성
2. **에셋 관리** 탭에서 배경 이미지와 오디오 업로드
3. **씬 편집** 탭에서 배경 설정 → 핫스팟 배치
4. **단어 관리** 탭에서 수집 가능한 단어 등록
5. **퍼즐 편집** 탭에서 정답 슬롯 구성
6. **검증** 탭으로 오류 확인
7. **익스포트**로 HTML 파일 생성
