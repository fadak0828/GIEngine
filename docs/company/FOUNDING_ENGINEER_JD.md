## About FADAK

FADAK is building GIEngine — a Golden Idol-style detective/deduction game engine that makes investigative puzzle game creation accessible through a professional editor, reliable runtime, and seamless standalone export.

Our mission is to empower game creators with professional-grade tools that were previously only available to large studios.

---

## The Role

As our Founding Engineer, you will be the technical backbone of FADAK's GIEngine division. This is a unique opportunity to shape the architecture and direction of a game engine from its formative stages. You will work directly with the CEO to translate vision into production-ready code.

**You will own:**
- Technical architecture decisions for GIEngine
- Core packages (`packages/core`, `packages/ai`)
- Code quality standards and build system
- Mentoring future team members on technical decisions

**You will tackle immediate priorities:**
1. Fix `@gi-engine/ai` build script blockers
2. Fix editor test fixtures for `subPuzzleId` type sync
3. Stabilize the monorepo build (`npm run ci:check` must pass)
4. Plan Phase 2 architecture (store/state-machine split)
